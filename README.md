## 💡 프로젝트 소개
병원을 추천하는 포털 사이트입니다.

## ✅ 개발 기간
* 25.07.21 ~ 25.08.26

## ⚙️ 개발 환경
- 언어 : JSX / SCSS / TS
- 프레임워크 : Next.js
- 라이브러리 : React
- 도구 : VS Code / Git
- 배포 : Github Pages

## ✨ 주요 기능
- 반응형 웹 디자인
- Interactive UI/UX
  * 무한 슬라이드
  * 픽셀 기반 분석 (pixel-based interaction)
  * Intersection Observer 애니메이션
  * 마우스 오버 & 클릭 애니메이션
